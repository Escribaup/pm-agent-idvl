Como funciona
  • Selecione uma pasta (ex: Google Drive / iDVL / PM-Agent /)
  • O app salva um .json por projeto nessa pasta
  • Sincronize via Google Drive para usar em outros computadores
  • Funciona no Chrome e Edge modernos (v86+)

O navegador pedirá permissão de leitura/escrita na pasta. Apenas Chrome e Edge suportam este recurso.
